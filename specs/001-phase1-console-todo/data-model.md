# Data Model: Phase I - In-Memory Python Console Todo App

**Feature**: Phase I - In-Memory Python Console Todo App
**Date**: 2026-01-01
**Purpose**: Define data entities, fields, validation rules, and state transitions for the todo application

## Entities

### Task

**Description**: Represents a todo item with unique identifier, title, description, and completion status.

**Fields**:

| Field | Type | Required | Default | Description |
|-------|------|----------|----------|-------------|
| id | int | Yes | Auto-generated | Unique identifier for the task, sequential starting from 1 |
| title | str | Yes | None | Task title, must be non-empty string |
| description | str | No | "" | Task description, optional, can be empty string |
| completed | bool | No | False | Completion status, True if task is finished, False if pending |

**Validation Rules**:

1. **ID Validation**:
   - ID must be positive integer (> 0)
   - ID must be unique within application session
   - ID is auto-generated by TaskManager, not user-provided

2. **Title Validation**:
   - Title must be non-empty string (len(title.strip()) > 0)
   - Title can contain ASCII and common Unicode characters
   - No maximum length specified (accepts reasonable lengths)

3. **Description Validation**:
   - Description is optional, can be empty string
   - If provided, can contain ASCII and common Unicode characters
   - No maximum length specified (accepts reasonable lengths)

4. **Completion Status Validation**:
   - Must be boolean value (True or False)
   - Defaults to False for new tasks
   - Can be toggled between True and False

**Python Implementation**:

```python
from dataclasses import dataclass

@dataclass
class Task:
    """Represents a todo item with unique ID, title, description, and completion status."""
    id: int
    title: str
    description: str = ""
    completed: bool = False

    def __post_init__(self):
        """Validate task fields after initialization."""
        if not isinstance(self.id, int) or self.id <= 0:
            raise ValueError("Task ID must be a positive integer")
        if not isinstance(self.title, str) or not self.title.strip():
            raise ValueError("Task title must be a non-empty string")
        if not isinstance(self.description, str):
            raise ValueError("Task description must be a string")
        if not isinstance(self.completed, bool):
            raise ValueError("Task completed status must be a boolean")

    def mark_complete(self) -> None:
        """Mark task as completed."""
        self.completed = True

    def mark_incomplete(self) -> None:
        """Mark task as incomplete."""
        self.completed = False

    def toggle_completion(self) -> None:
        """Toggle completion status between True and False."""
        self.completed = not self.completed

    def __str__(self) -> str:
        """Return human-readable string representation of task."""
        status = "✓" if self.completed else "○"
        return f"[{self.id}] {status} {self.title} - {self.description or '(no description)'}"
```

### TaskCollection

**Description**: Represents the in-memory storage of all tasks during the application session. Provides CRUD operations and filtering capabilities.

**Fields**:

| Field | Type | Required | Default | Description |
|-------|------|----------|----------|-------------|
| tasks | List[Task] | Yes | [] | In-memory list of Task objects |
| next_id | int | Yes | 1 | Counter for auto-generating unique task IDs |

**Operations**:

1. **Add Task**:
   - Input: title (str), description (str, optional)
   - Output: Task object with auto-generated ID
   - Behavior: Creates new Task with next_id, increments next_id, appends to tasks list
   - Validation: Title must be non-empty

2. **View All Tasks**:
   - Input: None
   - Output: List[Task] (copy of tasks list)
   - Behavior: Returns all tasks in insertion order

3. **View Tasks by Status**:
   - Input: completed (bool)
   - Output: List[Task] (filtered list)
   - Behavior: Returns tasks matching completion status

4. **Get Task by ID**:
   - Input: task_id (int)
   - Output: Task object or None
   - Behavior: Searches tasks list for matching ID, returns Task or None

5. **Update Task**:
   - Input: task_id (int), title (str, optional), description (str, optional)
   - Output: Updated Task object
   - Behavior: Finds task by ID, updates provided fields, returns updated task
   - Validation: Task ID must exist, at least one field must be provided

6. **Delete Task**:
   - Input: task_id (int)
   - Output: None
   - Behavior: Removes task with matching ID from tasks list
   - Validation: Task ID must exist

7. **Mark Task Complete/Incomplete**:
   - Input: task_id (int), completed (bool)
   - Output: Updated Task object
   - Behavior: Finds task by ID, updates completion status, returns updated task
   - Validation: Task ID must exist

**Python Implementation**:

```python
from typing import List, Optional
from task import Task

class TaskManager:
    """Manages in-memory storage and CRUD operations for Task objects."""

    def __init__(self) -> None:
        """Initialize empty task collection and ID counter."""
        self.tasks: List[Task] = []
        self.next_id: int = 1

    def add_task(self, title: str, description: str = "") -> Task:
        """Add a new task with auto-generated ID.

        Args:
            title: Non-empty string for task title
            description: Optional string for task description

        Returns:
            Task object with unique ID

        Raises:
            ValueError: If title is empty or whitespace only
        """
        task = Task(
            id=self.next_id,
            title=title,
            description=description,
            completed=False
        )
        self.tasks.append(task)
        self.next_id += 1
        return task

    def view_all_tasks(self) -> List[Task]:
        """Return all tasks in insertion order.

        Returns:
            Copy of tasks list (prevents external modification)
        """
        return list(self.tasks)

    def view_tasks_by_status(self, completed: bool) -> List[Task]:
        """Return tasks filtered by completion status.

        Args:
            completed: True for completed tasks, False for pending tasks

        Returns:
            List of tasks matching completion status
        """
        return [task for task in self.tasks if task.completed == completed]

    def get_task_by_id(self, task_id: int) -> Optional[Task]:
        """Find task by unique ID.

        Args:
            task_id: Positive integer task ID

        Returns:
            Task object if found, None otherwise
        """
        for task in self.tasks:
            if task.id == task_id:
                return task
        return None

    def update_task(
        self,
        task_id: int,
        title: Optional[str] = None,
        description: Optional[str] = None
    ) -> Task:
        """Update task title and/or description.

        Args:
            task_id: Positive integer task ID
            title: Optional new title string
            description: Optional new description string

        Returns:
            Updated Task object

        Raises:
            ValueError: If task ID not found or no fields provided
        """
        task = self.get_task_by_id(task_id)
        if task is None:
            raise ValueError(f"Task with ID {task_id} not found")

        if title is None and description is None:
            raise ValueError("At least one field (title or description) must be provided")

        if title is not None:
            task.title = title
        if description is not None:
            task.description = description

        return task

    def delete_task(self, task_id: int) -> None:
        """Delete task by unique ID.

        Args:
            task_id: Positive integer task ID

        Raises:
            ValueError: If task ID not found
        """
        task = self.get_task_by_id(task_id)
        if task is None:
            raise ValueError(f"Task with ID {task_id} not found")

        self.tasks.remove(task)

    def mark_task_completion(self, task_id: int, completed: bool) -> Task:
        """Update task completion status.

        Args:
            task_id: Positive integer task ID
            completed: True for complete, False for incomplete

        Returns:
            Updated Task object

        Raises:
            ValueError: If task ID not found
        """
        task = self.get_task_by_id(task_id)
        if task is None:
            raise ValueError(f"Task with ID {task_id} not found")

        task.completed = completed
        return task
```

## State Transitions

### Task Completion Status

```
[Incomplete (False)] ──mark_complete()──> [Complete (True)]
       ↑                                     ↓
       └───────mark_incomplete()──────────────┘
```

**Transitions**:
1. **Incomplete → Complete**: User marks task as complete via `mark_complete()` or `toggle_completion()`
2. **Complete → Incomplete**: User marks task as incomplete via `mark_incomplete()` or `toggle_completion()`
3. **Complete ↔ Complete**: No-op, task already in target state
4. **Incomplete ↔ Incomplete**: No-op, task already in target state

**No Other States**: Task has exactly two completion states (True/False), no intermediate states.

## Relationships

### Task and TaskCollection

**Relationship**: One-to-Many
- TaskCollection contains zero or more Task objects
- Each Task belongs to exactly one TaskCollection
- Task lifecycle: Created by TaskCollection.add_task(), retrieved/updated/deleted by TaskCollection methods

**No Other Entities**: Phase I has only Task and TaskCollection entities. No user accounts, no task dependencies, no metadata beyond title/description/completion.

---

## Data Integrity Rules

1. **ID Uniqueness**: TaskManager.next_id ensures each Task has unique ID
2. **ID Persistence**: Task IDs are not reused after deletion
3. **Title Required**: Task.__post_init__() enforces non-empty title
4. **Validation on Operation**: All TaskManager methods validate inputs before modifying tasks
5. **Immutability of ID**: Task ID cannot be modified after creation
6. **Optional Fields**: Description defaults to empty string if not provided, completion defaults to False
