# Quickstart Guide: Phase I - In-Memory Python Console Todo App

**Feature**: Phase I - In-Memory Python Console Todo App
**Date**: 2026-01-01
**Purpose**: Developer setup, running the application, and validation steps

## Prerequisites

### Required Software

1. **Python 3.13+**
   - Download from: https://www.python.org/downloads/
   - Install for your operating system (Windows, macOS, or Linux)
   - Verify installation:
     ```bash
     python --version
     # Should show: Python 3.13.x or higher
     ```

2. **UV Package Manager**
   - Installation instructions: https://github.com/astral-sh/uv
   - Windows:
     ```powershell
     irm https://astral.sh/uv/install.ps1 | iex
     ```
   - macOS/Linux:
     ```bash
     curl -LsSf https://astral.sh/uv/install.sh | sh
     ```
   - Verify installation:
     ```bash
     uv --version
     # Should show version number
     ```

### Verify Versions

```bash
python --version
uv --version
```

Both commands should execute without errors and show version numbers.

## Project Setup

### 1. Navigate to Project Root

```bash
cd D:\Quarter 4\Hackathon\hecakthon-II\todo-app
```

### 2. Initialize UV Environment

```bash
uv init
```

This creates a `pyproject.toml` file with basic project configuration.

### 3. Install pytest for Testing

```bash
uv add --dev pytest
```

This adds pytest to development dependencies in `pyproject.toml`.

### 4. Create Project Structure

```bash
# Create source directory
mkdir src

# Create tests directory
mkdir tests
```

### 5. Create pyproject.toml (if not auto-generated)

If `uv init` doesn't create `pyproject.toml`, create it manually:

```toml
[project]
name = "phase1-console-todo"
version = "0.1.0"
description = "Phase I: In-Memory Python Console Todo App"
requires-python = ">=3.13"
dependencies = []

[project.optional-dependencies]
dev = ["pytest"]

[build-system]
requires = ["hatchling"]
build-backend = "hatchling.build"
```



   ```
   3. Pending Tasks
   ```

3. **Mark Task Complete**:

4. **View Completed Tasks**:
   ```
   Enter your choice (1-6): 2

   View options:
   1. All Tasks
   2. Completed Tasks
   3. Pending Tasks

   [1] ✓ Buy groceries - Milk, eggs, bread
   ```

5. **Exit Application**:
   ```
   Enter your choice (1-6): 6

   Goodbye! Note: All tasks are in-memory only and will be lost on exit.
   ```

## Validation Steps

### 1. Validate All CRUD Operations

Perform the following sequence:

1. Add 3 tasks with different titles and descriptions
2. View all tasks - verify all 3 display correctly
3. Mark one task as complete
4. Update one task's title
5. Delete one task
6. View only completed tasks - verify only the marked task appears
7. View only pending tasks - verify remaining tasks appear
8. Exit and restart - verify no tasks remain (in-memory only)

**Expected Result**: All operations complete without errors, messages are clear and informative.

### 2. Validate Error Handling

1. Try to add a task with empty title → Should show error message
2. Try to update/delete/mark non-existent task ID (e.g., 999) → Should show "task not found" error
3. Try to view tasks when list is empty → Should show "No tasks found" message
4. Try to update task without providing new title or description → Should show error

**Expected Result**: All error messages are clear, user-friendly, and guide resolution.

### 3. Validate Console Output

1. Add a task with a very long title (>80 characters) → Should format readable without breaking
2. Add a task with special characters (emoji, Unicode) → Should display correctly
3. View tasks - verify status indicators are clear (✓ for complete, ○ for pending)

**Expected Result**: Output is consistent, readable, and fits terminal width.

### 4. Run Unit Tests

```bash
uv run pytest -v
```

**Expected Result**: All tests pass with no failures or errors.

### 5. Verify PEP 8 Compliance

```bash
# Install ruff (optional, for linting)
uv add --dev ruff

# Check PEP 8 compliance
uv run ruff check src/
```

**Expected Result**: No PEP 8 violations found.

## Troubleshooting

### Python Version Mismatch

**Error**: `Python version too old`

**Solution**: Install Python 3.13+ from https://www.python.org/downloads/

### UV Not Found

**Error**: `command not found: uv`

**Solution**: Reinstall UV using the installation commands in Prerequisites section.

### Import Errors

**Error**: `ModuleNotFoundError: No module named 'src'`

**Solution**: Ensure you're running from project root and `src/__init__.py` exists:

```bash
# Check __init__.py exists
cat src/__init__.py

# Should contain (at minimum):
# Empty file is fine, or:
__version__ = "0.1.0"
```

### Test Failures

**Error**: Tests fail with assertion errors

**Solution**: Review test output, compare expected vs actual values, and verify implementation matches contracts in `specs/001-phase1-console-todo/contracts/`.

### Output Formatting Issues

**Error**: Console output wraps poorly or is unreadable

**Solution**: Ensure `utils.py` formats output for 80-character width and uses consistent spacing and alignment.

## Development Workflow

### TDD Cycle (Red-Green-Refactor)

1. **Red**: Write a failing test for a feature
   ```bash
   uv run pytest tests/test_task_manager.py -v
   # Should show FAILED
   ```

2. **Green**: Implement minimum code to make test pass
   ```bash
   uv run pytest tests/test_task_manager.py -v
   # Should show PASSED
   ```

3. **Refactor**: Clean up code while keeping tests green
   ```bash
   uv run pytest tests/test_task_manager.py -v
   # Should still show PASSED
   ```

### Code Quality Checks

Run before committing:

```bash
# Run all tests
uv run pytest -v

# Check PEP 8 (if ruff installed)
uv run ruff check src/

# Format code (if ruff installed)
uv run ruff format src/
```
